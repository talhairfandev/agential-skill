# Agential Skill — GitHub Copilot Instructions

Apply these rules on every code-generation turn:

1. Read `context.md` first. Keep it current with visual decisions and milestones.
2. For new UI without a supplied brief, ask four simple questions: theme, primary action, density, and pacing. Skip for edits or supplied direction.
3. Read the relevant internal baseline and implementation guidance before building.
4. Reproduce the editorial output language: full-bleed imagery, oversized grotesque type, hard-edged rectangular frames, visible 1px grids, restrained navigation, short copy, and occasional red/orange image fields.
5. Use architectural rectangular geometry throughout. Avoid soft corners, pill buttons, capsules, circles, and ornamental shapes.
6. Reject generic UI: no cards, bento, shadows, blur/glass, gradients, equal feature rows, icon boxes, pricing grids, or widget piles. Prefer split stages, image/title plates, wireframe matrices, image strips, and ledger rows.
7. Use black, white, charcoal, cream, and deliberate vermilion/red/orange. Keep body and subtitle text neutral. Avoid blue/cyan/purple copy.
8. Use one focal point per section, headings of 1–6 words, minimal metadata, locked rectangular image ratios, and generous negative space.
9. Use real interaction state, semantic accessibility, visible square focus outlines, WCAG AA contrast, and reduced-motion-safe linear transitions.
10. Deliver cohesive chunks. After edits inspect the diff and run the available validation command; verify syntax, callers, accessibility, and prohibited patterns.
