# Portfolio Blueprints — Editorial Index and Image Archive

Use this reference for portfolios, personal sites, selected works, and case studies. The portfolio is an image archive with a typographic index, not a grid of product cards.

## Visual Direction

- Use full-bleed photography, sharp frames, oversized title type, visible construction rules, and sparse captions.
- Keep every surface and control hard-edged and rectangular. Avoid soft corners, pills, capsules, circles, shadows, glass, bento, and floating tiles.
- Let images, composition, and typography carry the story instead of interface chrome.

## Two-Level Architecture

### 1. Works Index
Minimal navigation, one dominant introduction, then a visual archive. Prefer an asymmetric editorial image grid or horizontal image strip with each work identified by `[ 01 ]`, title, year, discipline, and one short descriptor. Use real images and hard frames; never wrap work in a card shell.

### 2. Case Study
Sequence the project as a visual essay: title plate, one-sentence premise, full-bleed hero image, short fact line, process line, image details, and a closing index link. Let images do most of the explaining.

## Approved Interactions

Use only interactions that support browsing: image crop on hover, masked title reveal, keyboard-accessible horizontal gallery, sticky index label, or a restrained page transition. Do not add cursor bubbles, magnetic controls, decorative marquees, or motion that competes with the work. Disable transforms for reduced motion.

## Portfolio Gate

- One strong image or typographic anchor per section.
- Headings 1–6 words; captions and metadata concise.
- Rectangular `3/4`, `4/5`, or `16/9` images with `object-cover`.
- 1px rules used as layout structure.
- No generic cards, soft geometry, gradients, shadows, glass, or clutter.
