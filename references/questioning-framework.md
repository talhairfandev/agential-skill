# Questioning Framework — Editorial UI

Ask only when the user requests new UI without a supplied design brief. Skip for edits, bug fixes, and explicit visual direction.

## Core Questions

1. **Visual direction** — Should the page use a monochrome editorial field, black/cream with vermilion imagery, or a high-contrast image-led composition? The default is minimal image-led editorial output.
2. **Primary action** — What is the one action or outcome the page should make obvious?
3. **Density** — Should the page be a spacious visual essay or a tighter editorial index? Both remain sparse and avoid generic widgets.
4. **Pacing** — Should the first delivery be a navigation + hero image/title plate, followed by the index and supporting stages?

## Plain-English Format

Ask no more than 1–3 questions at once, offer 2–3 choices, and mark the editorial option as recommended. Do not ask for implementation jargon such as design tokens, routing strategy, or animation libraries before the visual direction is clear.

## Portfolio Requests

For portfolios and selected works, ask:

1. Is the work presented as a visual archive, a studio index, or a personal case-study journal?
2. Which composition leads: split stage, full-bleed title plate, wireframe matrix, or image strip?
3. Should the first screen emphasize one hero work or a typographic introduction?

All choices use the same hard-edged editorial system. Do not introduce a separate soft visual mode.
