# Section Benchmarks — Editorial Composition Catalogue

Use these composition patterns as the default visual language. Every section remains hard-edged, flat, image-led, and sparse.

| Composition | Signature treatment | Best use |
|---|---|---|
| **Swiss split stage** | split field, monumental type, restrained image plane | tools, portfolios, systems |
| **Luxury image plate** | full-bleed portrait, title overlay, tiny utility bar | fashion, retail, launches |
| **Wireframe matrix** | visible grid, placed monochrome images, short captions | editorial, advisory, healthcare |
| **Kinetic type field** | black/cream/red image texture and oversized type | studios, culture, experimental brands |
| **Editorial work grid** | architectural image/type grid with hard seams | agencies, architecture, portfolios |
| **Horizontal image strip** | rectangular image sequence, captions, directional controls | photography, case studies |
| **Stepped process line** | staggered numbered stages on flat planes | services, workflow, onboarding |
| **Futuristic image hero** | image-led red field with restrained controls | products, OS concepts |
| **Metrics timeline** | image-backed data sequence with hard rules | events, schedules, campaigns |

## Selection Rules

1. Pick one composition per section; do not combine every motif.
2. Replace any card-like block with a flat column, image frame, or shared-rule index row.
3. Keep the image dominant and metadata sparse.
4. Use black, white, charcoal, cream, and deliberate red/orange. Avoid decorative color systems.
5. Use `min-height` rather than fixed `height`; stack naturally on mobile.
6. Keep media and controls rectangular and architectural.

## Review

- [ ] One focal idea.
- [ ] Visible 1px structure where useful.
- [ ] Oversized type and concise copy.
- [ ] Real images, locked ratios, hard frames.
- [ ] No cards, bento, shadows, glass, pills, curves, or gradients.
